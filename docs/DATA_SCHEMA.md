# Input contract

`cohort.csv` is a local, already selected baseline cohort. Required model-loader columns:

eid, p4205_i0, p40007_i0, p21021_i0, p4199_i0, p4200_i0, p21022, p20160_i0, p20162_i0, p3616_i0, p3751_i0, p4717_i0, p2316_i0, sex

Additional frozen label columns: `exact_target`, `landmark_years_to_death`, `exact_early`, `exact_late`, `exact_late_mask`.

The source table supplied to `prepare_inputs.py` additionally requires `p53_i0` (baseline date) and `p40000_i0` (death-registry date). Only trusted registry dates should be used. The interval is elapsed days / 365.25; observed death requires a date at or before the administrative cutoff (default 2024-08-31). Main events satisfy 0 < interval <= 10 years. Participants without an observed death require ten years of potential follow-up. Invalid dates and non-positive death intervals are excluded. The legacy death-age column is only checked for a known death lacking a date; it is not used to calculate the label.

The source cohort must already satisfy the study population and waveform eligibility criteria. This helper is not a full UK Biobank extraction pipeline. Do not silently regenerate an original study split after excluding records.

`p4205_i0` is the stored 100-point waveform string accepted by `src/two_tower_torch_model.py`. Preserve the original coding of source fields (including categorical Yes/No values and unavailable responses); arbitrary numeric recoding will not be equivalent. Feature construction yields 126 engineered descriptors before training-fitted preprocessing; missingness indicators can change encoded width (155 or 157 in the study).

The local cache `p4205_advanced_features.csv` contains `eid` and the advanced feature columns generated by `p4205_advanced_features.py`. Summary and raw/difference statistics are built by the training pipeline. `data/splits/seed*.csv` contains `eid,split`, with split exactly train, validation or test, one row per participant. IDs must exactly match the cohort. The historical assignments were preserved from the earlier cohort definition; a newly stratified split is a new experiment.

Date fields, outcome labels and IDs are not predictors. Some source columns are retained by the legacy loader but excluded by the selected structured feature policy. Preprocessing is fitted on training participants only.
